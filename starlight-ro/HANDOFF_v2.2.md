# 星光冒險 v2.2｜改版與交接

日期：2026-10-15。原始碼版本：2.2.0。前一版：v2.1（原正式包資料夾名稱仍是「星光冒險_v2.0」）。

**交付狀態：程式整合、120 項自動測試與正式建置已通過；實機遊玩、畫面及錄影待補驗。** 使用者已明確決定先交付可啟動版本。未宣稱已達商業遊戲畫面品質，也未將舊版瀏覽器驗收套用到新版。

## 使用者要求與本次決策

- 先處理轉職、存檔，再改善介面、畫面、玩法。允許多代理平行分工，由主代理整合。
- 保留舊 v2 存檔、物品 ID、卡片規則、一般掉率與卡片升級成本。
- 使用者後續指示 Claude 額度已滿，這輪停止諮詢。曾準備網頁草稿，但沒有送出；沒有收到新一輪 Claude 意見。各分工交叉檢查是 Codex 靜態程式審查。
- 使用者目前只有 60Hz 螢幕，120Hz 留待設備驗收。瀏覽器操作連線逾時後，使用者同意「先整理可玩版本，實機驗收稍後補」。

## 不可改動的卡片規則

1. Q07／Q08：卡片插在目前穿著的裝備中，才提供技能模組資格。
2. Q09：拆裝免費且不消耗卡片；戰鬥中禁止改卡與配置的既有規則保留。
3. Q10／Q11：升級指定實體卡片，其他同名卡不繼承。素材限背包中、未鎖定、同名 Lv.1 卡，逐階需求仍為 1／2／3／4；升級必定成功。
4. 一般卡上限 Lv.5、MVP 卡上限 Lv.3；原強化係數、掉率及插槽規則不變。
5. 同名來源取最高等級，不疊加；拔掉來源保留技能配置，等待有效來源重新裝備。
6. 衍生效果不再觸發衍生效果。新相容性檢查只移除不能實際觸發的效果資格，不刪掉玩家舊設定。

本輪未補做 Q03 的特殊裝備跨職、二轉、倉庫或連線系統；它們是原 v2 系統尚未實作的後續內容，不能把本輪改善完成視為原始全部 GDD 功能完備。

## 存檔與啟動

- 正式版維持 `http://127.0.0.1:4200/`。使用原瀏覽器、原個人資料、相同網址，才能讀到原本的 v2 存檔。更換瀏覽器、使用無痕、改成 localhost 或改連接埠會是不同儲存位置。
- 原 v2.0 正式包保留，本輪不覆寫。v1.x 屬不同遊戲架構，不能直接匯入。
- 首次遷移會留存未修改的 `pre-upgrade-v2.2` 快照，另有健康輪替備份。損毀主檔可另保留 `corrupt-main` 證據。這些都在該瀏覽器 IndexedDB 中，不等於外部檔案備份。
- 遊戲內設定可匯出／匯入角色；清除角色保留上述恢復證據，但清除瀏覽器網站資料會一併刪除。原始遷移快照暫無獨立下載按鈕，維護時可透過 `SaveStore.preUpgradeBackup()` 取得。
- 地面掉落只保留同次遊玩跨圖，不包含完整關閉或重新整理後恢復。MVP 則有持久化重生時間。
- 新啟動器辨識當前建置；若 4200 正在執行不同版本，會提示關閉舊啟動服務，不會把舊版當新版打開，也不會任意換網址造成角色看似消失。
- 多分頁寫入鎖維持啟用。若出現已在另一分頁開啟，回原分頁重新整理，或關閉舊遊戲分頁後重開。

## 驗證證據

- 整合前基線：39 項測試。
- 最終整合：`npm test -- --maxWorkers=1 --no-file-parallelism`，**8 個檔案、120／120 通過**，17.68 秒，2026-10-15 20:24:44 開始。未延長測試 timeout；先前平行驗證曾發生 timeout／worker 通訊逾時，單 worker 重跑通過。原始輸出附於 `驗證紀錄/tests-final.log`。
- `npm run build`：型別檢查與 Vite 正式建置成功，32 個模組，建置 13.29 秒。輸出附於 `驗證紀錄/build-final.log`。
- 三名分工完成規則／模擬／UI 靜態交叉審查，並修正導航完成狀態、死亡對話、急救補學、舊配置顯示、背景縮放、圖格邊界與貼圖累積問題。
- 使用原 v2.1 程式產生人工測試角色，確認退款／遷移資料；全程未讀取或改寫使用者的正式角色存檔。
- 另有三職業各 20 分鐘虛擬時間模擬：使用有限藥水、實際買賣、返城／死亡耗時。劍士 Base13／Job10、法師 13／9、弓手 14／11；各死亡 1 次。這是加速模擬，不是 20 分鐘真人遊玩。詳見 `驗證紀錄/balance-20min.jsonl`。
- 遊戲包另以獨立測試服務核對首頁、CSS、JS 的回應與檔案雜湊；結果以附帶 `交付驗證.json` 為準。HTTP 成功僅證明資源可載入，不證明渲染或操作成功。

## 尚待實機補驗

瀏覽器曾載入新版建角畫面，後續操作逾時，重新取得分頁及建立內建瀏覽器也失敗。因此未完成新版建角後遊玩，未錄影、未量測 FPS、未確認音效。

1. 原瀏覽器以 v2.0／v2.1 角色開新版：角色、裝備、精煉、卡片 ID／等級、模組與急救退款正確；再重新整理核對。
2. 新角色完成初心者流程、轉職、買裝備、插卡、配置模組；三職業實際戰鬥與三種 MVP 預警符合判定。
3. 1280×720 與 1440×900，90／100／115% 介面比例，視窗拖動與輸入保留；確認字體、遮擋、對話及底部按鈕。
4. 八方向起步／停步／轉向、裝備外觀、魔物動畫、換圖與連續戰鬥至少 10 分鐘；60Hz 前景錄影、音效與記憶體觀察。
5. 120Hz 留待具備該螢幕時補驗，不能以 60Hz 或模擬通過替代。
6. 真人評估任務導航是否易懂、三職業練等速度、補給成本與後期流派強度；依結果再調整，不能由短時自動模擬認定長期平衡完成。
