# 星光冒險 v2.0｜交接說明

製作：Claude Opus 5.5，2026-10-15。使用者對 v1.1.2 不滿意，要求「依照你的想法整個大改，要像 RO 新世代的誕生」。這版是**從頭重寫**的新專案，不是 v1.x 的修改。v1.x 原始碼與正式包都原樣保留。

## 位置

| 項目 | 路徑 |
| --- | --- |
| 原始碼 | `outputs/starlight-ro-v2` |
| 正式包 | `outputs/星光冒險_v2.0`（port **4200**） |
| 開發 | `npx vite --port 4201`，`art.html` 是美術預覽頁（不會打包） |
| 測試 | `npm test`（32 項）、`npm run build` |

## 和 v1.x 最大的不同

| 面向 | v1.x | v2.0 |
| --- | --- | --- |
| 視角 | 俯視 2D | **斜 45 度 isometric**（RO 式） |
| 移動 | 直線走，穿過障礙 | **A\* 格子尋路**，會繞路；按住滑鼠持續移動 |
| 成長 | 一開始就有全部技能 | **初心者 → 職業 Lv.10 轉職**；Base/Job 分開、技能點、技能樹、前置條件 |
| 素質 | 4 項 | **STR/AGI/VIT/INT/DEX/LUK**，加點成本遞增 |
| 戰鬥 | 投射物 ARPG | **點怪自動普攻**、HIT/FLEE 判定與 Miss、爆擊、**施法讀條**、技能延遲、屬性相剋 |
| 地圖 | 一大張 | **4 張地圖以傳送點相連**，每張野外都有 MVP |
| 美術 | 外部生成 PNG | **全部程式繪製**（角色 5 方向 × 13 格、10 種怪、地形、建築、圖示） |

## 保留的使用者決策（Q01～Q11）

卡片規則全部照 GDD：
- 卡片插在**穿著中**的裝備才生效（Q07、Q08）。
- 插拔免費無損（Q09），戰鬥中不能操作（GDD 6.4）。
- 重複卡只升級指定的那一張，消耗同名 Lv.1 安全素材，數量 1/2/3/4（Q10、Q11）。
- 同名卡取最高等級、不疊加。
- 模組依技能語意標籤檢查是否相容（Q06）。
- 係數 +7/+14/+22/+30%，MVP 卡 +14/+30%（GDD 6.2）。
- 掉率 1/150、MVP 1/6（GDD 7）。
- 死亡懲罰：Lv.10 以下不扣，之後扣 2%（GDD 7）。
- MVP 沒有無敵或必做機制（Q02）。

衍生效果不會再觸發衍生效果（回響、脈動、連鎖、碎冰都標記為 derived），沒有 A→B→A 無限連鎖。

## 架構

```
src/
  data/      jobs.ts（職業、技能樹、經驗曲線）monsters.ts items.ts（裝備、卡片、模組、商店）maps.ts
  rules/     state.ts — 權威存檔狀態＋所有指令（純函式，丟出錯誤訊息給玩家看）
  world/     grid.ts（A*）mapgen.ts（可重現的地圖產生）sim.ts（60Hz 固定步長戰鬥模擬，只發事件）rng.ts
  render/    iso.ts scene.ts（Phaser，插值繪製）art/（程式繪製的角色、怪物、地形、圖示）
  ui.ts      DOM 介面（RO 風格視窗）
  main.ts    協調者：事件 → 規則 → 存檔
  save.ts    IndexedDB 單一快照＋備份
  audio.ts   WebAudio 合成音效（沒有音檔）
```

原則：
- `rules/` 不碰畫面。
- `world/` 不碰存檔。
- `render/` 不改狀態。
- 所有存檔變更都走 `main.run()`。

- 型別檢查、正式建置、正式包 4200 啟動與所有檔案 HTTP 200。
- 內建瀏覽器（Canvas 模式）實際操作過：
  - 建角
  - 城鎮 → 草原傳送
  - 自動戰鬥擊殺與經驗入帳
  - 自動撿取
  - 轉職法師
  - 學技能、放快捷欄
  - 火焰矢擊殺

  - 死亡與回存檔點
  - 森林與洞窟畫面

## 未驗證／已知限制

- **流暢度與動畫**：測試用的瀏覽器在背景時每秒只有約 1 格，無法判斷實際手感。要在使用者的 Chrome（WebGL）實測。
- 技能特效的畫面效果只做了程式檢查，沒看到實際動畫。
- 音效沒有實際聽過。
- 尚未實作：
  - 二轉
  - 精煉
  - 倉庫
  - 任務
  - 組隊
  - 特殊裝備跨職（Q03 的「少數特殊裝備可突破」）
  - 卡片買回
- 數值（怪物血量、經驗曲線、技能倍率）都是待實玩調整的初始值，集中在 `data/` 資料夾。

## 建議下一步

1. 使用者實玩回饋：手感、難度、練等速度。
2. 依回饋調整 `data/monsters.ts` 和 `data/jobs.ts` 的數值。
3. 加任務、倉庫、精煉。
4. 加二轉與跨職特殊裝備（Q03）。

## v2.1 更新（2026-10-15）

使用者要求「看哪裡可以加強、更好玩，直接做」。

| 項目 | 內容 | 檔案 |
| --- | --- | --- |
| 任務 | 11 個依序解鎖的委託，有擊殺、收集、轉職三種。在嚮導 莉莉交件，畫面有進度欄 | `data/quests.ts`、`rules/state.ts`（`questStatus`、`noteKill`、`completeQuest`）、`ui.ts` |
| 精煉 | +0～+7，+4 前 100%，之後 80/60/40%。失敗只扣 Zeny，不降級、不損壞。精煉師 布魯 | `rules/state.ts`（`refine`）、`ui.ts` |
| 自動戰鬥 | 會用快捷欄技能，增益沒掛就補；不挑 MVP、等級差 >6 的怪、或待機 MVP 周圍 9 格內的怪 | `world/sim.ts`（`autoCast`、`autoBattle`） |
| 自動喝藥 | 設定 HP 門檻，由強到弱選藥水 | `main.ts`（`autoPotion`） |
| 快捷欄 | 學會的主動技能自動放進第一個空格 | `rules/state.ts`（`learnSkill`） |
| MVP | 每 8 秒預警重擊（1.3 秒，走出圈就閃得掉），半血召喚 4 隻小怪（不會重生）。沒有無敵（Q02） | `world/sim.ts`（`mvpSpecials`） |
| 法師 | 杖普攻改為 6 格魔法彈（100% MATK），攻速加快，火焰矢等詠唱改成 0.5 秒×等級 | `world/sim.ts`、`data/jobs.ts` |
| 平衡 | 經驗曲線改為 `10+6·lv²`、怪物經驗約 ×1.5～2、森林與洞窟怪物攻擊下修約 25%、主動怪偵測從 7 格改為 5.5 格、劍士 HP 係數 8、SP 回復 ×2 | `data/` |
| 音樂 | 每張地圖程式合成的背景音樂 | `audio.ts`（`playMusic`） |
| 商店 | 加入騎士長劍、複合弓、鐵盔、星紋法袍、鎖鍊甲 | `data/items.ts` |
| 存檔相容 | `normalizeGame` 補上新欄位，v2.0 存檔可以繼續用 | `rules/state.ts`、`save.ts` |

**平衡模擬**：`MIN=60 npx vite-node tools/balance.ts`，讓三個職業各自自動戰鬥 60 分鐘。

| --- | --- | --- |
| 劍士 | Base 23 | 5 |
| 法師 | Base 19 | 2 |
| 弓手 | Base 28 | 2 |

約 5 分鐘轉職。模擬不會買裝備，實際練等會更快。
