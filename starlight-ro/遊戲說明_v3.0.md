# 星光冒險 v3.0｜遊戲說明

## 怎麼開始

1. 雙擊「開始遊戲.command」，跳出來的黑色視窗要保持開著。
2. 瀏覽器會打開 **http://127.0.0.1:4200/**。
3. 同一個瀏覽器、同一個網址，原本 v2 的角色會直接延續，而且會自動補上 v3.0 的新欄位。
4. 如果出現「同一個網址正在執行另一版」，先在舊版的黑色視窗按 Ctrl+C 關掉，再重開這一版。

## v3.0 新內容

### 3D 畫面（預設）
- Q 版 3D 角色：會眨眼、會變表情的動畫大眼睛，瀏海和鬢髮，各職業服裝、披風與武器。
- 卡通描邊、即時影子、泛光、霧氣、日夜循環（晚上路燈和窗戶會亮）、會動的水面。
- 天氣粒子：草原有花瓣、森林有螢火蟲、洞窟有雪、神殿有星光。
- **滑鼠右鍵拖曳**可以旋轉視角，**滾輪**縮放。
- 想用舊的 2D 畫面：設定 →「畫面模式」選 2D，再重新整理。

### 寵物（按 P）
- 道具商店買「星光誘捕器」。
- 把魔物打到剩少少的血，用滑鼠指著牠，再按誘捕器，就有機會捕捉。血越低越容易成功；MVP 不能抓。
- 寵物會跟著你，提供能力加成。親密度達 250 後加成全開，一起打怪會慢慢增加親密度。
- 共 10 種寵物，例如林間精靈 INT +2、火狐 DEX +2、狼 ATK +8。

### 外觀（按 V）
- 晨光鎮西邊的「造型師 露娜」有販售：貓耳、兔耳、蝴蝶結、花冠、小惡魔角、天使光環、星星魔女帽、天使之翼、精靈薄翼、小惡魔翅膀、英雄披風。
- 打倒果凍國王會解鎖限定的「噗噗背包」。
- 外觀只改變樣子，不影響能力。

## 三職業的追求流派

按 **S** 打開技能視窗，最上方的「成長指南」可以選流派，會列出素質順序、技能路線、要找的卡片和裝備（含掉落來源）。按 **A** 狀態視窗可以看到詠唱、攻速、技能延遲，以及「零詠唱所需 DEX」。

### 法師・零詠唱
- 詠唱 = 1 − DEX÷150 − 裝備詠唱%。
- 詠唱裝備：魔導耳環 −8%、時之沙漏 −15%、賢者眼鏡 −6%、時光斗篷 −6%、秘術長袍 −5%、星辰法杖 −10%。
- 全套約 −42%，DEX 約 88 就能完全零詠唱；有一半裝備時，DEX 70 左右詠唱就很短了。
- 再把時晶詠唱卡裝到火焰矢上，還能再縮短。
- 零詠唱之後的瓶頸是 SP 和施放後延遲，所以下一步是魔力節約、迅捷收招、魔力湧現。

### 劍士
- **暴擊重斬**：LUK、戰士頭巾、幸運草、流星劍，加上銳眼、致命一擊、破甲三張卡。重斬爆擊率超過 40%，爆擊會無視防禦，打神殿守衛這類硬怪特別有感。
- **不倒鐵壁**：VIT、守護戒指、鎖鍊甲，搭配吸取和森之息，幾乎不用喝藥。

### 弓手・疾風連射
- 攻速裝備：迅捷手環、獵人帽、疾風披風、疾風弓。
- 加上 AGI，普攻間隔可以壓到約 0.3 秒。
- 分裂箭讓二連矢每一箭再多一箭，輕羽靴和迅捷收招讓技能接得更緊。
