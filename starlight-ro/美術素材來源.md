# 星光冒險 v2.2｜美術素材來源

更新日期：2026-10-15。

本專案的圖像由專案內的 Canvas 繪圖程式產生，未使用 RO、楓之谷或其他遊戲的原圖、截圖、拆包素材或商標。遊戲風格參考不代表素材授權來源。

| 內容 | 原始檔 | 本次來源及處理 |
| --- | --- | --- |
| 人物、髮型、職業服裝 | `src/render/art/characters.ts` | 沿用使用者交付的 v2 程式繪圖；本輪新增 8 格走路、裝備配色、帽子、精煉光暈及圖格裁切，均為新撰寫繪圖程式 |
| 魔物與動態圖格 | `src/render/art/monsters.ts` | 沿用 v2 原始程式圖像，搭配場景的受擊／死亡呈現；沒有新增外部貼圖 |
| 地面、樹木、房屋、傳送點 | `src/render/art/world.ts` | 沿用 v2 程式圖像；本輪改善前景遮擋與貼圖重用 |
| 遠景、旅人營地、古樹石碑、洞窟封印地標 | `src/render/art/backdrop.ts` | 本輪原創程式繪圖，使用 Canvas 幾何、漸層與路徑產生 |
| 道具、卡片及技能圖示 | `src/render/art/icons.ts` | 沿用 v2 專案內程式圖像 |
| 介面外觀 | `src/style.css`、`src/ui.ts` | 本輪自行設計奶油色、森林綠與金色的版面及樣式；使用系統字型 |
| 技能特效、MVP 預警、導航 | `src/render/scene.ts` | Phaser Graphics 程式繪製；本輪增加方向型預警、路線、打擊線與地標互動 |
| 音效、背景音樂 | `src/audio.ts` | 沿用 v2 的 WebAudio 程式合成，沒有外部音檔 |

v2 原始交接文件記載製作者為 Claude Opus 5.5；這是使用者交付版本的來源紀錄。本輪修改由 Codex 與其分工代理完成，沒有取得新一輪 Claude 審核，也沒有把舊回覆當成本次意見。

本輪未使用影像生成工具，因為現有遊戲採程式繪圖，這次直接延伸其圖格、外觀與場景系統。Phaser 引擎的第三方授權另附 `THIRD_PARTY_LICENSES.md`。
