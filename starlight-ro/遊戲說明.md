# 星光冒險 v2.1｜遊戲說明

> 這是舊版歷史說明。新版請讀「遊戲說明_v2.2.md」與「HANDOFF_v2.2.md」。

RO 風格的單人網頁 RPG。斜 45 度地圖，點地走路、點怪自動攻擊，從初心者開始練功轉職。

## 開始遊戲

1. 雙擊「開始遊戲.command」，保持跳出來的視窗開著。
2. 瀏覽器會自動打開 **http://127.0.0.1:4200/**。
3. 取名字、選髮型和髮色，按「開始冒險」。

存檔在這個瀏覽器裡，和舊版（4188、4190）是分開的。v2.0 是全新的遊戲系統，舊版角色不能搬過來。

## 操作

| 操作 | 說明 |
| --- | --- |
| 左鍵點地面 | 自動尋路走過去，會繞過樹和房子；按住可以一直跟著滑鼠走 |
| 左鍵點魔物 | 走過去並連續普攻 |
| 左鍵點 NPC／地上物品 | 對話／撿起來 |
| `1`～`9` | 快捷欄（技能、藥水）。攻擊技能會打滑鼠指著的怪，或目前的攻擊目標 |
| 右鍵 | 取消技能選擇 |
| `A` `E` `Q` `S` `C` | 狀態、道具、裝備、技能、卡片冊 |
| `Z` | 自動戰鬥（手動走路或點怪就會關閉） |
| `X` | 坐下（HP、SP 回復加倍） |
| `Esc` | 關閉視窗／設定 |
| 滾輪 | 縮放畫面 |

## 怎麼玩

1. **初心者**：打倒魔物拿基本經驗和職業經驗。
   - 基本等級提升 → 拿**素質點**，按 `A` 分配 STR／AGI／VIT／INT／DEX／LUK。素質越高，加 1 點要花越多點數。
   - 職業等級提升 → 拿**技能點**，按 `S` 學技能。
2. **轉職**：職業等級 10，而且**基本技能**學到 Lv.9 後，找晨光鎮北邊的**轉職官 葛蘭**，可以轉成：
   - **劍士**：重斬、烈焰爆破、挑撥、鐵壁意志、劍術精通。
   - **法師**：火焰矢、冰霜矢、雷鳴矢（技能幾級就落幾支）、爆炎球、冰封術、雷暴。有詠唱時間，DEX 越高唸越快。
   - **弓手**：二連矢、箭雨、專注凝神、震退箭、鷹眼專注、遠射。
3. **卡片**：每種魔物都有自己的卡片，掉率很低（一般 1/150、MVP 1/6）。
   - 按 `Q` 打開裝備視窗，點卡槽「＋」插卡。插拔免費，但戰鬥中不能操作。
   - 按 `S` 在技能旁邊的「模組」選單裝上卡片的效果，例如吸血、緩速、回響、連鎖、中毒。
   - 卡片要插在**穿著中**的裝備裡才會生效。
   - 重複的卡片可以在卡片冊（`C`）升級**其中一張**，升級一定成功。
4. **地圖**：晨光鎮 → 晨光草原（Lv.1～12）→ 翠影森林（Lv.10～22）→ 寒晶洞窟（Lv.18～35）。
   - 每張野外地圖都有一隻 **MVP 魔王**。
   - 站上地圖邊緣的光圈就會傳送到下一張地圖。
5. **城鎮 NPC**：道具商（藥水、回城羽毛）、武器防具商、卡片研究員、星語服務員（記錄存檔點、付費傳送）。
6. **死亡**：Base Lv.10 以前不會損失經驗；之後每次倒下扣該等級所需經驗的 2%。裝備和卡片不會掉。

## v2.1 新增

- **任務**：找嚮導莉莉接委託。共 11 個任務，從打果凍一路到挑戰冰霜巨像。左上角會顯示進度，完成後回去找莉莉領 Zeny、經驗和道具。
- **自動戰鬥會放技能**：會使用快捷欄上的攻擊技能和增益技能。
  - SP 低於 25% 時改用普攻。
  - 不會主動去打 MVP 或高你太多級的怪。
- **自動喝藥**：在設定裡選 HP 低於多少時自動喝藥（預設 30%）。
- **學會的技能自動放到快捷欄**。
- **精煉師 布魯**：在廣場西南邊，可以把裝備精煉到 +7。
  - 武器每 +1，攻擊 +3；防具每 +1，防禦 +1。
  - +4 以前一定成功。失敗只扣 Zeny，**裝備不會壞**。
- **MVP 大招**：
  - MVP 會在你腳下畫出紅色預警圈，1.3 秒後重擊，看到就快走開。
  - 血量剩一半時會叫出小怪。
- **法師普攻**：拿杖時會射出魔法彈（射程 6 格）。
- **背景音樂**：每張地圖不同，可以在設定裡關掉。
- **武器防具店**：新增劍士、法師、弓手的進階裝備。

## 設定

按「設定」可以：
- 開關自動撿取
- 自動喝藥
- 背景音樂
- 調整音量
- 測試用掉率倍率（正式為 ×1）
- 匯出／匯入存檔

清除瀏覽器網站資料會刪除存檔，建議偶爾匯出備份。
