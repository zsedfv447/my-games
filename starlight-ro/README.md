## 開發

本次使用 Node.js 22.11.0。依鎖定檔安裝依賴，再執行：

```sh
npm ci
npm test -- --maxWorkers=1 --no-file-parallelism
npm run build
npm run dev -- --port 4212 --strictPort
```

開發網址的存檔與正式版 `http://127.0.0.1:4200/` 分開。正式包只需要 macOS 的 Python 3，無須安裝 Node.js。

固定步長模擬與畫面插值必須保留。卡片規則不可任意改動，下一輪請先讀最新交接文件與測試。
