# 星光冒險 v2.2｜遊戲說明

從初心者出發，在晨光鎮接委託，探索草原、森林與冰洞，轉職成劍士、法師或弓手，收集裝備和怪物卡片，組合自己的技能玩法。

## 開啟與繼續角色

1. 完整解壓縮「星光冒險_v2.2.zip」。
2. 雙擊資料夾內的「開始遊戲.command」，保持跳出的終端機視窗開著。
3. 瀏覽器會開啟 `http://127.0.0.1:4200/`。若原本已有遊戲分頁，直接回該分頁重新整理。

若出現另一版本正在執行，先在舊版啟動終端機按 Control＋C，再啟動新版。若 Mac 阻擋第一次開啟，可在 Finder 按右鍵選「打開」。請勿直接雙擊 `game/index.html`。

**沿用 v2.0／v2.1 角色：必須使用原本的瀏覽器、個人資料與上述網址。** 更換瀏覽器、無痕視窗、localhost 或其他連接埠，會讀到另一個儲存位置。v1.x 是不同遊戲，角色不相容。遊戲不是雲端存檔，請定期到設定匯出備份。

## 基本操作

| 操作 | 用途 |
| --- | --- |
| 點地面／按住滑鼠 | 尋路移動，繞過障礙物 |
| 點魔物 | 接近並持續普通攻擊 |
| 點 NPC／地上道具 | 對話／撿取 |
| `1`～`9` 或 `F1`～`F9` | 使用對應快捷欄的技能或道具 |
| 快捷欄空格點擊、右鍵或 Shift＋點擊 | 選擇技能／道具，或清空該格 |
| 右鍵點遊戲場景 | 取消正在選擇目標的技能 |
| `A`／`E`／`Q`／`S`／`C` | 狀態／背包／裝備／技能／卡片冊 |
| `Z` | 開關自動戰鬥；手動移動或點怪會停止 |
| `X` 或 `Insert` | 坐下休息，加速恢復 |
| `Esc` | 關閉介面或開設定；死亡時保留復活按鈕 |
| 滾輪 | 縮放遊戲場景；介面大小另外在設定調整 |

## 第一段冒險

1. 建立角色後，找**嚮導莉莉**接委託。點左上方任務追蹤可引導到目標地圖；完成後返回莉莉交件。
2. 在**晨光草原**打噗噗果凍、小綠蟲，獲得基本經驗與職業經驗。按 `A` 分配素質、按 `S` 學技能，視窗內也有成長指南。
3. **基本技能 Lv.3 自動學會急救，不花技能點**；快捷欄有空位時會自動加入。先前版本付費學過急救的角色，新版會一次退還那 1 點。
4. 職業等級達 **10**，基本技能達 **Lv.9**，找**轉職官葛蘭**選擇劍士、法師或弓手。
5. 向武器防具商購買合適裝備，點背包中的裝備查看比較，雙擊穿上。精煉師**布魯**可精煉到 +7；+4 以前必定成功，失敗不損壞裝備。

一般委託與三個 MVP 挑戰已分開；不用先打倒果凍國王才能繼續森林的委託。導航沿路仍可能遇到主動魔物，需注意補給。

## 卡片與技能模組

卡片冊 `C` 可查看每張卡片的來源魔物、地圖及相容技能，即使還沒收集也能查。

1. 在裝備視窗 `Q`，把卡片插進目前穿著裝備的相容卡槽。
2. 到技能視窗 `S` 選擇對應模組，才會對該技能生效。
3. 拔卡免費且卡片不消失。失去裝備來源後，原模組設定保留但暫停，重新裝備有效來源就能恢復。
4. 重複卡可升級**指定的單張卡片**。素材限未鎖定、背包中的同名 Lv.1 卡，逐階消耗 1／2／3／4 張，一定成功。一般卡最高 Lv.5、MVP 卡最高 Lv.3；其他同名卡不會跟著升級。
5. 同名卡同時裝備時取最高等級，不累加。戰鬥中不能改卡或模組配置。

裝備可鎖定，避免誤賣。最近售出的 10 件裝備可按原售出價買回；裝備內的卡片在出售時已退回背包，買回後需自行重插。升級過或鎖定的卡片不能販賣。

## 三職業與強敵

- **劍士**：近戰、範圍清怪與耐久。指南提供重斬／爆破及續戰方向。
- **法師**：火、冰、雷法術，詠唱與屬性選擇。法杖近距離普通攻擊也使用魔法攻擊力。
- **弓手**：遠距離、箭雨與爆擊方向。保持距離並留意走位路線。

晨光草原、翠影森林、寒晶洞窟各有一隻 MVP。留意果凍國王的躍擊圈、古樹守護者的多處根束、冰霜巨像的方向重擊，及時離開預警範圍。強敵沒有新增無敵階段；擊殺後須等待重生，切圖或重新整理不會立即刷新。

場景內的營地與石碑可點擊調查，了解地點故事。這些是探索地標，不額外發放經驗或獎勵。

## 自動戰鬥與設定

自動戰鬥有**均衡、範圍優先、節省 SP**三種策略。會依目標、屬性、怪物數量及 SP 挑選快捷欄技能，仍要自己配置技能與補充藥水。

設定可調整自動撿取、自動喝藥門檻、缺藥停止尋怪、委託完成停止尋怪、音量與音樂、90／100／115% 介面大小，亦可重設視窗位置。正式版掉率固定為原本設定，沒有測試倍率選單。

背景分頁會暫停戰鬥。自動尋怪會避開 MVP 作為主動目標，但不保證移動途中完全不會遇到強敵。

## 存檔與驗收狀態

遊戲會自動存檔，並保留健康備份。設定可以匯出文字存檔；將文字另存成檔案，之後可貼回匯入。讀取失敗不會直接用新角色覆寫原檔。重新整理前，尤其剛取得重要道具時，可先匯出一份備份。

這份交付已通過 **120 項程式測試及正式建置**。依你的決定，實機畫面、戰鬥手感、60Hz 錄影及音效稍後補驗；120Hz 另待設備測試。完整變更與限制見 `HANDOFF_v2.2.md`。
