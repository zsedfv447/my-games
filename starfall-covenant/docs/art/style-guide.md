# 《星骸契約》原創美術風格指南 v1

目的：把目前「扁平繪本風」的程式產生美術，提升到商業轉珠 RPG 的完成度，同時保持完全原創。
參考來源：神魔之塔參考包（只看品質與節奏，見 [asset-license-review.md](asset-license-review.md)）。本文件只描述**抽象原則與本作自己的規格**，任何素材都不得照描、裁切、調色或拼貼參考圖。

---

## 0. 從參考包學到什麼，以及本作怎麼不一樣

| 參考作品做得好的地方（抽象原則） | 本作的做法（必須不同） |
|---|---|
| 一張卡只有一個主屬性色，全畫面 70% 以上都是同色系，一眼看出屬性 | 照做這個原則，但色票用本作的 `ORB_COLORS`，並且一律加「星光金」點綴當品牌色 |
| 角色被屬性特效（水流、火焰、藤蔓）環繞，輪廓外側有強烈邊緣光 | 本作的環繞特效統一成「星紋線」：細金線連成星座，沿角色外輪廓轉一圈，再依屬性加材質（焰＝火星、潮＝水泡、森＝葉片、輝＝光塵、蝕＝墨霧） |
| 珠子很粗獷：不規則岩石、厚黑描邊、中央刻符號，縮到 40px 仍清楚 | 本作的星紋珠是**圓形拋光星晶**：正圓、透明玻璃感、內部有星屑、符號是發光的刻線。保留「厚描邊、大符號、小尺寸可讀」，不做岩石不規則外形 |
| 卡框分層：外框 → 稀有度裝飾 → 屬性徽 → 種族徽 → 名字底板 | 照這個層次，但外形改成本作的「星盤」框：圓角矩形＋四角星芒＋上緣弧形星軌 |
| 消除與傷害特效節奏快，Combo 數字很大、逐步放大 | 照做節奏規格（見第 4 節），視覺改用星光爆散、星座連線 |

**禁止事項**：不做岩石符石外形、不做「神／魔」字樣或神魔母題、不用黑底金框加屬性旗的頭像樣式、不放任何參考包的圖（含縮圖與描圖）。

## 1. 色彩

### 1.1 全域色票（已在 `theme.css`，維持不變）
- 底：`--bg #0b1230`、`--bg-deep #060a1f`、`--bg-elev #16204a`
- 品牌金：`--gold #f2c45a`、`--gold-soft #f7dc98`、`--gold-deep #b98a2a`
- 文字：`#eef1ff`／`#9aa4d6`／`#6570a8`

### 1.2 屬性三階色（每個屬性多加兩階，供立繪、特效用）

| 屬性 | 暗部 | 中間 | 亮部 | 新增：高光 | 新增：特效核心 |
|---|---|---|---|---|---|
| 焰 | `#8f2414` | `#e8553f` | `#ffb199` | `#ffe3c4` | `#fff4d6` |
| 潮 | `#163f8a` | `#3f8ee8` | `#a8d4ff` | `#dff1ff` | `#f2fbff` |
| 森 | `#1d6634` | `#4cbf6a` | `#b5f2c4` | `#e4ffd9` | `#f6fff0` |
| 輝 | `#a0700f` | `#f2c45a` | `#fff1c2` | `#fffbe8` | `#ffffff` |
| 蝕 | `#4a2183` | `#9b5de5` | `#dcc0ff` | `#f1e4ff` | `#ffd6ff` |
| 心 | `#b03c78` | `#ff8fc1` | `#ffd6ea` | `#fff0f7` | `#ffffff` |

### 1.3 比例
- 立繪：屬性色 70%、底色（深藍）20%、星光金 ≤10%。
- 明度分布：背景暗（L 10–25%）、角色中間調、特效與邊緣光最亮。最亮的地方只能在角色臉部附近或武器尖端。
- 6★ 卡可以有第二屬性色當點綴，但不超過 15%。

## 2. 卡片

### 2.1 立繪（`cardPortraitSvg`，300×400，或使用者提供的原創圖）
- 構圖：角色占畫面高 75–90%，頭頂留 8%，腳可以出框。視線方向朝畫面中心。
- 三層景深：
  1. 背景：屬性色徑向漸層＋該角色專屬星座（已有 `constellationPoints`），星點加十字光芒。
  2. 角色：剪影清楚，外輪廓 2px 深色描邊＋1.5px 屬性亮部邊緣光（只在背光側）。
  3. 前景特效：星紋線繞角色一圈（貝茲曲線，2–3 段），沿線撒屬性材質粒子 12–30 顆。
- 稀有度差異：
  - 3★：只有背景＋角色。
  - 4★：加星紋線一段。
  - 5★：星紋線兩段＋粒子。
  - 6★：星紋線三段＋粒子＋背景大型星座紋章（半透明 20%）。
- 程式產生版的角色：用「剪影＋符號」做，不畫人臉。依種族用不同剪影模板（獸＝四足、龍＝翼與長尾、機構＝齒輪方形、靈仙＝羽翼、冥裔＝斗篷與燈、人傑＝人形持武器），由卡號種子決定姿勢與配件，6 種族 × 3 姿勢起跳。

### 2.2 卡框層次（由下到上）
1. 底板：`--bg-deep`，圓角 20（300×400 尺寸下）。
2. 立繪。
3. 下方暗角：底部 30% 由透明漸層到 `#060a1f` 85%，讓名字可讀。
4. 稀有度外框：寬 9，漸層用 `RARITY_FRAMES`；5★ 以上加內側 1px 亮線與外發光。
5. 四角星芒：4★ 以上出現，大小依稀有度 8／11／14px，顏色同外框亮部。
6. 上緣星軌：5★ 以上，一條細弧線＋3 顆星，表示「星盤」框，是本作識別。
7. 屬性徽（左上）：圓形，直徑 44，內放屬性符號（同珠子符號）。
8. 種族徽（右上）：膠囊形，文字種族名。
9. 名字底板：底部，名字用 `--font-title`、粗 900、白字深色描邊；稀有度星數在名字上方。

### 2.3 頭像（`cardIconSvg`，100×100）
- 從立繪臉部附近裁切（使用者圖片時取上 1/3 中央），不要整張縮小。
- 外框寬 5，屬性徽縮到左下 22px，種族字右上。
- 頭像在隊伍列只有 56px 寬：所有元素需在 56px 下測試可讀。

## 3. 星紋珠（`orbSvg`，100×100，Canvas 繪製）

- 外形：正圓，半徑 42，**外描邊 4px 屬性暗部色**（現在是 3px，加粗）。
- 材質（由下到上）：
  1. 徑向漸層：中心偏左上 `亮部` → 55% `中間` → 100% `暗部`。
  2. 內陰影：下緣一道 8px 暗部色弧，做出球體厚度。
  3. 星屑：6–10 顆 1–2px 的白點，透明度 40–80%，位置依珠種固定（不要每顆隨機，Canvas 快取才有效）。
  4. 符號：白色 92%，2.5–3px 暗部描邊；外加 2px 屬性高光色外發光，像刻在玻璃裡發光。
  5. 主高光：左上橢圓，白 35%；新增右下小反光點，白 25%。
- 狀態：
  - 強化珠：外圈虛線光環＋右上四芒星（現有）＋符號外發光加倍。
  - 鎖定珠：維持十字鎖鏈，改成星金色鎖頭。
  - 毒珠／隱藏珠：維持現有設計。
- 尺寸測試：40、56、72px 都要能分辨六種珠（含色弱模擬）。

## 4. 特效節奏（`board-view.ts` 與戰鬥畫面）

| 事件 | 時長 | 規格 |
|---|---|---|
| 拖曳中的珠 | 持續 | 放大 1.15 倍，下方 0.25 格偏移，加屬性色外光 |
| 拖曳軌跡 | 持續 | 星金色細線 3px，尾端淡出 300ms |
| 每組消除 | 每組 180ms，間隔 120ms | 珠子縮小到 0＋白閃 1 幀＋4–8 顆星芒向外飛 24px |
| Combo 數字 | 每次 +1 時彈跳 160ms | 從 1.4 倍縮回 1 倍；5 Combo 起字變金色，10 Combo 起加外發光 |
| 天降補珠 | 220ms，ease-out | 由上方落下，最後 40ms 輕微回彈 |
| 角色攻擊 | 每位 250ms，間隔 80ms | 頭像上跳 6px＋屬性色光彈飛向敵人 |
| 傷害數字 | 600ms | 由敵人中心上浮 30px，剋制時放大 1.3 倍並帶屬性色描邊 |
| 主動技 | 900ms | 全畫面暗 40% → 角色立繪從側邊滑入 300ms → 技能名橫幅 400ms → 淡出 200ms |
| 戰鬥加速 ×2 | — | 以上全部時長除以 2 |

原則：同一時間最多三種動畫疊加；任何特效不得擋住盤面超過 300ms。

## 5. 介面排版（390×844 設計尺寸）

- 戰鬥畫面上下比例：敵人區 38%、隊伍列 10%、血條 4%、盤面 48%。盤面 6×5，每格 = 寬度 / 6。
- 盤面底：深藍格子，奇偶格明度差 4%，外框 2px `--line-strong`，四角星芒。
- 隊伍列：6 個頭像等寬，CD 就緒時頭像外框星金色呼吸光（1.2s 週期）。
- 血條：圓角膠囊，生命漸層 `#5fd39a → #2fa36a`，受傷先白色殘影 400ms 再縮短。
- 主選單：底部 5 個導覽按鈕，圖示 24px＋文字 11px；選中時圖示上方出現小星點。
- 面板：`--bg-elev` 底、1px `--line` 框、圓角 14；標題列左側 4px 星金色短線。

## 6. 背景與場景

本作地名與場景（皆原創）：灰燈港（邊境港鎮、霧中路燈）、墜域（星骸汙染的大地、浮空碎石、紫色裂縫）、穹頂（雲上星座遺跡、白石與金色星軌）。

- 背景一律直式 390×844（或 2 倍），上方 40% 可以有細節，下方 60% 要暗而單純，因為會被盤面與介面蓋住。
- 每章一張戰鬥背景＋一張 Boss 背景（Boss 版加紅或紫色調、更強的光柱）。
- 程式產生版：遠景剪影 3 層（視差）＋星空（`starfieldSvg`）＋場景主題物（燈塔、浮石、星環）。

---

## 7. 敵人

- 依敵人所屬墜域的屬性上色，外形是「被星骸侵蝕的生物」：身上一定有發紫或發屬性色的晶體裂紋，這是本作敵人的識別。
- Boss 尺寸為一般敵人 1.6 倍，有專屬頭冠或光環。
- 程式產生版：在現有 `enemySvg` 基礎上加晶體裂紋、眼睛發光、3 種體型模板。
