# 流派總表（卡片 × 流派分配）

> 由總監維護。創意顧問依此表提案角色設定與技能；戰鬥負責人依此表確認效果積木足夠；關卡與經濟負責人依此表安排取得途徑。
> 修改本表需經總監審核。

## 卡號規則
- `c{屬性}{格位}`：屬性 1=焰、2=潮、3=森、4=輝、5=蝕；格位見下表。
- `c6xx`：活動／挑戰之塔限定卡。`c9xx`：素材卡。
- 每個屬性 8 位角色、12 個卡號（5★ 與 3★ 可進化，進化後另給卡號）。

| 格位 | 稀有度 | 取得 | 備註 |
|---|---|---|---|
| 01 | 6★ | 限定卡池 | |
| 02 → 03 | 5★ → 6★ | 常駐卡池 | 角色 A |
| 04 → 05 | 5★ → 6★ | 常駐卡池 | 角色 B |
| 06 | 4★ | 常駐卡池／關卡掉落 | 角色 a |
| 07 | 4★ | 常駐卡池／關卡掉落 | 角色 b |
| 08 | 4★ | 常駐卡池／關卡掉落 | 角色 c |
| 09 → 10 | 3★ → 4★ | 關卡掉落 | 角色 C |
| 11 → 12 | 3★ → 4★ | 關卡掉落 | 角色 D |

## 流派代號
`mono` 單屬爆發｜`rainbow` 七彩齊攻｜`combo` 連擊狂潮｜`chain` 長串貫穿｜`heart` 心之守護｜`race` 種族羈絆｜`enhance` 強化珠增幅｜`control` 時之控場｜`berserk` 背水一戰｜`dual` 雙屬共鳴｜`skillcycle` 技能循環｜`fixed` 固定傷害

## 檢查
- 12 個流派各有 ≥1 張抽卡隊長、≥1 張免抽隊長 ✓
- 六種族各有 ≥1 張隊長 ✓（龍嗣有抽卡與免抽以外的支援要靠種族分配補足）
- **種族分配**：由創意顧問替 43 位角色指定種族，條件是每個種族 ≥6 位角色、且每個種族至少橫跨 3 個屬性。
