## 遊玩與搬存檔

交付的 `星骸契約_個人遊玩版.html` 已內嵌程式、圖片、音樂與音效，可直接用 Chrome 開啟，無需伺服器或網路。先點擊畫面才會播放音樂。單一檔案約31 MB。

存檔儲存在目前瀏覽器的本機資料。原 GitHub 網站與本機檔案的存檔空間不同：先在原網站「設定 → 匯出存檔碼」，在本機版「設定 → 匯入存檔碼」。之後固定使用同一份檔案路徑，移動檔案或更換瀏覽器前先匯出備份。
