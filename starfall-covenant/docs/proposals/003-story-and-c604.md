## 0. 格式與資料

- 每句對白對應 `StoryLine { speaker?: string; text: string }`，沒寫說話者的是旁白。
- 建議新增 `data/story.json`，格式為 `Record<string, StoryLine[]>`，`StageDef.story` 的 `before`／`beforeBoss`／`after` 填下表的劇情 id。檔名與格式由總監決定，通過後我把文字寫進去。
- 主角在台詞裡用「契印師」稱呼（存檔可改名，對白不直接寫名字，避免名字代入失敗）。
- 每章四段：開頭（x-1 before）、中 Boss 前（x-4 beforeBoss）、章節 Boss 前（x-9 beforeBoss）、章節結尾（x-9 after）。

| 劇情 id | 用在 |
|---|---|
| `prologue` | 新遊戲序章（取代目前 `story.ts` 的示範） |
| `ch{1-5}-open`／`-mid`／`-boss`／`-end` | 每章 x-1 before、x-4 beforeBoss、x-9 beforeBoss、x-9 after |
| `ch4-stars` | 第 4 章星章全滿（c604 加入） |
| `ev-beast-1`…`ev-beast-5`、`ev-beast-end` | 活動「獸王的召集令」 |
| `tower-30` | 挑戰之塔頂層（c603 加入） |

## 1. 故事主線（一段話）

見習契印師在灰燈港覺醒，和鐵匠之女蘿希一起出發，依序淨化五座墜落的星座遺跡。每打倒一隻章節 Boss，星骸碎片就會讓主角看到同一幕：七曜碎裂的那一晚，一道胸口帶著完整七曜星紋的影子舉起了手。天文台台長歐倫預言「星座還會再碎一次」，而主角漸漸發現，自己掌心的星紋與那道影子的星紋形狀相同。第 5 章在冥河河底與「碎曜之影」交手，影子退去前留下一句話，v0.1 結束在通往穹頂的路上。

3. 邊境小鎮灰燈港，今晚的燈又滅了一盞。
4. **？？？**：……聽得見嗎？讀得懂星紋的人。
5. **？？？**：握住那顆珠子。從今天起，你就是契印師了。
6. **蘿希**：喂！你也看到了吧？剛剛天上掉下來的那道光！
7. **蘿希**：你的手……那是星紋？跟我手套上這個一樣！
8. **蘿希**：太好了，我一個人去荒原會被老爸罵死，兩個人就不算亂跑了。

## 3. 第 1 章　獸座・焦骨荒原

**`ch1-open`**
1. 灰燈港外的荒原，草全是焦黑的，像被什麼東西燒過一整遍。
2. **提米**：嗚喔！嗚喔！（海豹揮著小旗子，拚命比著「危險」的旗語）
3. **蘿希**：這隻海豹是港口的提米。牠說……荒原的野獸都瘋了？
4. **蘿希**：以前荒原的狼看到人都會躲起來，現在卻成群結隊往港口跑。
5. **蘿希**：一定是那道光害的。我們去看看！
6. **提米**：嗚喔！（把旗子塞進你手裡，跟了上來）
7. 契印師的掌心微微發熱。荒原深處，有什麼東西在呼喚星紋。
8. **蘿希**：記住，把同樣顏色的珠子排成一排就能攻擊。我爸說打鐵也是一樣，要趁熱一口氣！

**`ch1-mid`**（1-4 墜骸熊王・巴格）
1. **蘿希**：那、那隻熊也太大了吧！背上插著的是……星骸碎片？
2. **蘿希**：牠受傷之後好像會變得更硬，趁牠還沒發怒前一口氣解決！
3. **提米**：嗚喔！（快打旗語：連、續、攻、擊）

**`ch1-boss`**（1-9 星骸獸祖・獠吼）
1. 荒原盡頭的巨大骨骸上，一頭燃燒的巨獸緩緩站起。
2. **蘿希**：那是……獸座的星靈？怎麼會變成這樣……
3. **獠吼**：契印師……又是契印師……當年也是你們這樣的人，讓星空碎掉的。
4. **獠吼**：滾回去！獸座的碎片，誰都別想拿走！
5. **蘿希**：牠的身體一直在擋水的力量……光靠剋制屬性打不穿，換別的顏色試試！

**`ch1-end`**
1. 獠吼倒下，胸口的碎片浮了起來，落進契印師的掌心。
2. 一瞬間，眼前出現了不屬於這裡的夜空：七個星座排成一圈，然後一道影子舉起了手。
3. 那道影子的胸口，有一枚完整的七曜星紋。
4. **蘿希**：喂！你怎麼了？突然站著發呆。
5. **蘿希**：……看到了奇怪的東西？那個等一下再說，先把這些傢伙帶回港口吧。
6. **波可**：（一隻縮成球的刺蝟從骨骸下滾出來，躲到你的腳邊）
7. 苔背刺蝟・波可加入了隊伍。荒原的野獸慢慢安靜下來，遠處傳來一聲很老的獅吼。

## 4. 第 2 章　工匠座・鏽齒工坊

**`ch2-open`**
1. 灰燈港天文台。一位駝背的老人正盯著星盤，連客人進門都沒抬頭。
2. **歐倫**：你就是帶回獸座碎片的契印師吧。坐，別碰那個，那個也別碰。
3. **歐倫**：我算了四十年，結論只有一個：星座會再碎一次。
4. **普莉茲**：老師又在嚇人了……不過碎片的光譜確實跟四十年前的紀錄一樣。
5. **帕奇**：（齒輪咔嗒咔嗒地轉）紀錄。下一顆碎片，墜落座標：東邊的鏽齒工坊。
6. **歐倫**：工匠座的遺跡。那裡的機械已經自己運轉了很多年，沒有人回來過。
7. **蘿希**：機械？那我最在行了！打鐵跟修東西差不多吧？
8. **歐倫**：……差很多。帶上帕奇，它記得每一條路。

**`ch2-mid`**（2-4 熔軌暴走車）
1. **帕奇**：警告。前方軌道車失控。速度過快，轉珠時間將被壓縮。
2. **蘿希**：時間變短的話……就提早用技能，別等到最後一秒！
3. 軌道上，一台燃燒的車頭朝你們衝了過來。

**`ch2-boss`**（2-9 鏽冠工匠王・卡斯鐸）
1. 工坊最深處，一張由零件堆成的王座上，坐著一具戴著鏽冠的巨大機械。
2. **卡斯鐸**：入侵者。工匠座的王座只差最後一塊碎片就完成了。
3. **卡斯鐸**：碎片答應過我：只要王冠完整，我就能把星座重新造出來。
4. **帕奇**：警告。對象不受延遲影響，並會週期性封印技能。
5. **蘿希**：等等……它的手臂上有一個跟熔軌一模一樣的標記！

**`ch2-end`**
1. 王座崩落。一台小小的履帶工匠機從廢鐵堆裡衝出來，抱住卡斯鐸的手臂。
2. **卡朵**：主人！我把軌道鋪過來了……我找到你了！
3. **卡斯鐸**：……卡朵？我在這裡坐了多久了？
4. **卡斯鐸**：碎片在我耳邊說話。它說，有人正在把碎片收集起來，而我只要先一步……
5. 碎片落入掌心，那道影子再次出現。這一次，影子轉過了頭。
6. **麥塔**：（工坊的守衛機站了起來）M-7 重新啟動。指揮權轉移：契印師。
7. 黃銅守衛・麥塔加入了隊伍。

## 5. 第 3 章　羽座・雲林

**`ch3-open`**

3. **琪雅**：我是羽座合唱團的領唱。大家都被風吹散了，我一直吹集合笛，可是回來的越來越少。

6. **琪雅**：不是打樹……是打附在樹上的東西。拜託你們。
7. **芙洛**：（一隻光蝶落在你肩上，灑下五顏六色的光粉）
8. **琪雅**：芙洛說，牠會幫你們補上缺的顏色。

**`ch3-mid`**（3-4 狂嵐羽后・希爾薇）

3. **希爾薇**：……不認識。光，熄掉吧。（輝紋珠一顆顆暗了下去）

**`ch3-boss`**（3-9 墜羽聖樹・枯冠之母）
1. 雲林正中，一棵巨樹的半邊已經枯成白骨的顏色。

3. **琪雅**：地上的那一半？聖樹的根……一直往下長到了大地。
4. **枯冠之母**：你們身上有她的味道。是她叫你們來的嗎？
5. **蘿希**：它越拖越強！別讓它把回復封住，速戰速決！

**`ch3-end`**

2. 遙遠的地面上，一棵千年巨樹的心形花，輕輕開了一瓣。
3. **琪雅**：聖樹說……它和地上的樹母是同一棵樹。墜落的時候，被扯成了兩半。
4. **琪雅**：附在它身上的碎片，原本是想去找另一顆碎片的。好像有人在叫它們。

6. **琪雅**：我跟你們走。笛聲能傳得更遠的話，大家一定會回來的。
7. 羽葉精靈・琪雅加入了隊伍。
