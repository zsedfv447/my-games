## 行為與範圍

- 未見過卡片不再顯示問號或剪影；真名、卡面、數值、主動技/CD、隊長技、流派角色、進化前後、取得方式全部可讀。
- 星紋覺醒沿用既有說明函式，標示為可解鎖效果，不假裝已覺醒。
- 見過／已取得／已領獎仍分開；沒有新增背包卡、收集進度、成就或星晶。未取得領獎仍停用且底層拒絕。
- 沒改存檔格式、戰鬥、轉珠助手、流派資料、角色資料、經濟或部署設定。

## 驗證方法

- 新增 `tests/encyclopedia-screen.test.ts`：真實DOM渲染（happy-dom），遍歷全部卡片與所有流派篩選；姓名/技能/CD/數值/覺醒/進化、可導覽、未取得不能領獎、瀏覽存檔不變、取得狀態區分、錯誤ID。
- 新增 `tests/encyclopedia-coverage.test.ts`：型別/定義雙向一致、標籤/試煉/流派圖鑑/篩選覆蓋、所有權與獎勵不變。
- TDD：變更前DOM測試3失敗/1通過，失敗為問號名字、格子無真名、進化缺入口；變更後通過。
- 基準完整測試106檔981項通過。最終完整測試108檔990項通過（新增6項DOM、3項純函式）；`npm run build`（TypeScript＋Vite）成功，`git diff --check`通過。build仍有大型chunk（>500kB）提示，npm亦提示環境http-proxy設定將棄用。
- 真Chromium未能啟動：環境禁止Unix socket；升權嘗試由sandbox啟動器失敗，沒有存取受限路徑，也沒有再嘗試繞過。故未宣稱真瀏覽器、截圖、手機真機或視覺排版驗證。happy-dom不替代這些驗證。

- 篩選返回測試曾失敗：happy-dom逐個插入帶selected屬性option時回報錯誤value，已用獨立DOM最小重現確認；select建好後明設value與保留條件同步，測試保留且最終通過。未宣稱此為真瀏覽器既有bug。
- DOM測試使用screen render與導航spy，涵蓋入口參數與重新render的保留篩選，不是完整router端到端測試。
